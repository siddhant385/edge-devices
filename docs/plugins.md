# Plugins Architecture

The edge AI pipeline uses a sequential, pipeline-based plugin architecture. The `core.processor.Processor` runs frame data through an ordered series of plugins defined by `ENABLED_PLUGINS`.

## FrameContext Lifecycle

A `FrameContext` object carries all data for a single processed frame through the plugin chain. This includes raw frame images, timestamp data, and accumulating lists of features (detections, tracks, evidence) generated by the plugins.

Lifecycle:

1.  **Creation**: Instantiated by the `Processor` when a new frame is read. Populated with raw camera frame (BGR NumPy array), timestamp, frame sequence number, device, and camera ID.
2.  **Pipeline Iteration**: Passed sequentially through every initialized plugin.
3.  **Feature Accumulation**: Plugins analyze the `FrameContext` and append their results (e.g., bounding boxes) to `context.features`.
4.  **Serialization**: If `context.features` contains actionable items (or if empty detections are allowed), the context is transformed into a standard JSON alert payload.

## Built-in Plugins

The platform includes five built-in plugins in the `plugins` module, accessed by short names:

### 1. `object_detection`
The foundational plugin. Executes an ONNX object detection model (using YOLO architecture defaults) against the frame.
*   **Reads**: `context.frame`
*   **Writes**: A `Feature` of type `"object_detection"` holding Roboflow Supervision `Detections`.
*   **Configuration**: `confidence_threshold`, `nms_threshold`, `target_class_ids`.

### 2. `object_tracking`
Applies ByteTrack across consecutive frames to maintain object identities.
*   **Reads**: The last added `"object_detection"` feature from `context.features`.
*   **Writes**: A `Feature` of type `"object_tracking"` holding updated `Detections` with tracker IDs.
*   **Configuration**: (Requires `object_detection` to precede it).

### 3. `intrusion_detection`
Filters detections down to only those whose bounding box centers fall within a predefined polygon zone.
*   **Reads**: The last added feature containing `Detections`.
*   **Writes**: A `Feature` of type `"intrusion_detection"` containing the filtered subset.
*   **Configuration**: `intrusion_zone_polygon` (must be configured).

### 4. `virtual_border`
Analyzes object tracks to determine if they crossed a specific two-point line segment in the current frame.
*   **Reads**: The last added `"object_tracking"` feature (tracking is mandatory).
*   **Writes**: A `Feature` of type `"virtual_border_crossing"` containing only the objects that crossed the line.
*   **Configuration**: `virtual_border_line` (must be configured).

### 5. `evidence_capture`
Attaches base64-encoded JPEG image evidence to a specific, pre-existing feature event in the `FrameContext`.
*   **Reads**: `context.frame` and the feature named in `evidence_source_feature`.
*   **Writes**: Modifies the target feature by populating its `evidence` byte string.
*   **Configuration**: `evidence_source_feature`, `evidence_max_width`, `evidence_jpeg_quality`.

## How to Write a Custom Plugin

Custom plugins implement the `Plugin` Protocol defined in `plugins.base`.

1.  **Create a module**: Write a Python module defining a class with `__init__(settings)` and `process(context)`.
2.  **Define Process Logic**: Read existing state from the `FrameContext` and append your results as a new `Feature`.
3.  **Use Roboflow Supervision**: Wrap all bounding box logic inside `sv.Detections`.

```python
# my_custom_plugin.py
from core.models import FrameContext, Feature
from config.settings import Settings
import supervision as sv

class AnimalCountPlugin:
    """A custom plugin that counts specific target classes."""
    def __init__(self, settings: Settings):
        self.animal_class_id = 15 # e.g. cat
    
    def process(self, context: FrameContext) -> None:
        if not context.features:
            return
            
        # Get latest detections
        latest_feature = context.features[-1]
        detections: sv.Detections = latest_feature.data
        
        # Filter logic
        animal_detections = detections[detections.class_id == self.animal_class_id]
        count = len(animal_detections)
        
        if count > 0:
            # Emit a new feature event
            context.features.append(Feature(
                feature_type="animal_alert",
                data=animal_detections,
                metadata={"animal_count": count}
            ))
```

To run it, configure `ENABLED_PLUGINS=object_detection,my_custom_plugin:AnimalCountPlugin` and ensure `my_custom_plugin.py` is in the Python path.
